# OVERDRIVE CITY（超速之城）

**一座城市。五颗星。零规则。**

一款原创的浏览器 **3D 开放世界飞车沙盒**——偷车、接活、在一座程序生成、
拥有完整昼夜循环的城市里甩开警察。仅一个 vendored 依赖、无构建步骤、
零资源文件：打开 `index.html` 即玩。

**▶ 在线试玩：[appleweiping.github.io/overdrive-city](https://appleweiping.github.io/overdrive-city/)**

## 这是什么？

一封写给开放世界犯罪类型游戏的情书，同时也是一次极限实验——
浏览器在几乎一无所有的情况下能走多远：

- **唯一依赖，直接入库。** [Three.js](https://threejs.org) r160 被拷进
  `lib/` —— 没有 npm、没有打包器、没有构建步骤、没有 lockfile。
  纯 ES 模块，静态文件直接跑。
- **零资源文件。** 每栋楼、每辆车、每个行人和每棵树都是程序生成的几何体；
  每个声音——引擎、枪声、警笛、爆炸、过关音效——都由 Web Audio API
  实时合成。仓库里没有图片（文档除外）、没有模型、没有音频。
- **确定性城市。** 同一个种子永远生成同一座 768 × 768 米的城市：同样的街道、
  同样的高楼、同样的公园。改一个 [`src/config.js`](src/config.js) 里的数字，
  就能得到一座新城。
- **一切原创。** 原创代码、原创名字、原创地图。类型即致敬——
  这里没有任何来自商业游戏的素材。

## 玩法循环

步行闲逛，或随便开走一辆车——路边停的、路上跑的都行（车主会有意见）。
地图上散落的彩色光柱提供 **十种程序生成的差事**：温和的一端是送货、
载客、计时赛和漂移合约；另一端是按订单偷车、诱饵逃亡和悬赏。
犯罪来钱快——但犯罪*很吵*：

- 犯罪积累**热度**，每 20 点热度点亮一颗通缉星（最多 5 颗）。
- 警察先步行响应，然后开巡逻车，再往后就直接**撞你**。
- 热度只有在脱离所有警察视线 4 秒后才开始衰减——
  切断视线、钻进小巷、消失。
- 站着不动被围住就是 **BUSTED**（现金 −20%）；被打死就是 **WASTED**
  （−30%）。在 3★+ 存活，城市每 30 秒付你 100 美元表演费。
- 犯罪任务的黑钱在**甩掉通缉前处于待入账状态**——逃脱本身就是工作的一部分。

存款就是你的分数，最佳纪录保存在本地。

## 操作

**步行**

| 按键 | 动作 |
|---|---|
| `W A S D` | 移动（相对相机方向） |
| `Shift` | 冲刺 |
| 鼠标 | 环绕相机 / 瞄准 |
| 左键 | 拳击 / 射击 |
| `1` `2` `3` / `Q` | 拳头 · 手枪 · 冲锋枪 / 切换 |
| `F` / `E` / `回车` | 进入最近的车（有人开就是抢车） |

**驾驶**

| 按键 | 动作 |
|---|---|
| `W` / `S` | 油门 / 刹车与倒车 |
| `A` / `D` | 转向 |
| `空格` | 手刹——这就是漂移键 |
| `F` / `E` | 下车（约 30 km/h 以下） |

## 差事图鉴

走进或开进彩色光柱即接单。每个任务都是新生成的——随机目标、随机路线，
报酬按距离、通缉风险和时段缩放（夜间 ×1.2）。

| 光柱 | 差事 | 规则 |
|---|---|---|
| 🟡 | **COURIER 限时快递** | 一个包裹、一个地址、一个倒计时。鼓励超速，不鼓励撞灯柱。 |
| 🟠 | **RUSH HOUR 多点急送** | 3–5 个投递点共用一个计时器，顺序随意——路线自己规划。 |
| 🔵 | **GYPSY CAB 黑出租** | 无证载客。只要你够自信，任何偷来的车都是出租车。小费看车速。 |
| 🟣 | **GHOST RUN 无声运送** | 全程不惹一颗星。0★ 双倍报酬，每多一星减半，3★ 直接失败。 |
| 🟢 | **BOOST 偷车订单** | 买家指定要*那辆*车，且要无损。找到它、开走它、当作你从没碰过它。 |
| 🔴 | **GETAWAY 亡命逃脱** | 开局即背着 2–4★。先甩掉热度，再抵达安全屋。 |
| 🔷 | **STREET CIRCUIT 街头计时赛** | 检查点竞速。铜牌管温饱，金牌 2.2 倍。 |
| 💗 | **SIDEWAYS 漂移合约** | 在标记区域内刷漂移分。连击倍率最高 3×，碰撞即清零。 |
| 🟤 | **TURF HOLDOUT 地盘保卫战** | 顶住 3–4 波武装暴徒的进攻。离开区域 10 秒即告吹。 |
| ❤️ | **BOUNTY 悬赏目标** | 有保镖的目标。保镖会还手。概不退款。 |

Boost、Holdout、Bounty 的报酬**甩掉通缉后才入账**——干完活，先消失，再收钱。

> 基调说明：平民永远不会成为任务目标，他们只会逃跑；所有需要你对付的人
> 都是持械的敌对分子。卡通式犯罪，没有血腥内容。

## 实现原理

整个游戏约 3500 行纯 ES 模块（[`src/`](src/)），无框架、无物理引擎。
完整调参表见 [docs/DESIGN.md](docs/DESIGN.md)，这里挑几个亮点：

**一个数组驱动整个世界。** 城市生成器输出一张 96×96 的 `Uint8Array`
瓦片图，这一个结构同时支撑：碰撞（圆 vs 瓦片、滑动响应）、警察视线
（瓦片 DDA 光线步进）、车道（每格路面存一个方向码，右侧通行）、
任务选点（可采样瓦片列表）。没有物理引擎，没有导航网格。

**漂移模型只有一个参数。** 每步把车速分解为前向/侧向分量，侧向速度按
`exp(−grip·dt)` 衰减。手刹只是把 grip 换成一个小得多的常数——
甩尾、侧倾、胎痕、漂移得分全部由 `|vL|` 自然涌现。

**通缉系统是一只长了眼睛的漏桶。** 犯罪加热度（每秒封顶）、星级 =
热度 ÷ 20，衰减由每个警察的瓦片 DDA 视线检查把关——所以逃脱是空间
问题，不是等计时器。升级压力（步警 → 巡逻车 → 撞击车）是每星一档的
生成预算。

**十种任务，三套脚手架。** 所有原型都由同样的原语组合而成：点对点
跑腿（快递/出租/无声/逃脱）、波次刷兵（保卫战、保镖）、水位线检查
（热度上限、车况、漂移连击）。新增一种任务约 40 行代码。

**渲染器绝不碍事。** 静态城市约 10 个 draw call（合并的顶点色地面 +
每类道具一个 `InstancedMesh`）。粒子是一个预分配 600 槽位的 `Points`
点云；曳光弹是 24 条池化线段。模拟跑在固定 60 Hz 累加器上，任何刷新率
下物理表现一致。HUD 是纯 DOM——文字和模糊由浏览器合成器免费渲染，
不占 WebGL 预算。

**昼夜是九个关键帧。** 天空、雾、太阳、环境光在关键帧表间插值；
`nightFactor` 渐变开关 900 个预置的自发光窗户、路灯、所有车辆的车灯，
以及玩家车上两盏真实聚光灯。唯一投影的太阳带着 140 米阴影盒跟随玩家。

```
index.html            入口——import map、HUD DOM、标题画面
lib/three.module.js   唯一的 vendored 依赖（Three.js r160）
src/
  config.js           全部调参常量
  rng.js              种子随机数（mulberry32）
  city.js             瓦片图、分区、建筑、车道、视线、路口图
  citymesh.js         实例化城市几何
  daynight.js         太阳、雾、关键帧天空
  vehicle.js          驾驶模型、损伤、车车碰撞
  traffic.js          循车道 AI、停靠车、抢车
  peds.js             平民、警察、帮派 AI、逃跑/敌对状态
  police.js           热度、星级、视线衰减、升级、逮捕
  weapons.js          hitscan 战斗
  missions.js         任务框架 + 10 种原型
  player.js           步行控制、上下车、追逐相机
  effects.js          池化粒子、曳光、爆炸
  audio.js            合成引擎/警笛/枪声/音效
  hud.js / minimap.js DOM HUD + 旋转小地图
  input.js / main.js  输入边沿 + 固定步长主循环
```

## 本地运行

纯静态文件，任何文件服务器都行：

```bash
git clone https://github.com/appleweiping/overdrive-city.git
cd overdrive-city
python -m http.server 8000        # 或：npx serve
# 打开 http://localhost:8000
```

（ES 模块需要 `http://` 协议——用 `file://` 直接打开 `index.html` 不行。）

推荐桌面浏览器 + 鼠标。需要支持 WebGL2；核显可稳 60 fps，
软件渲染下也能跑约 45 fps。

## 改着玩

所有东西都是 [`src/config.js`](src/config.js) 里的常量：城市尺寸和种子、
车辆手感、热度数值、警力预算、武器数据、任务经济。改 `SEED` 换一座新城；
把 `CAR_GRIP_HANDBRAKE` 降到 0.6 体验溜冰场漂移；觉得自己够快就调高
`COP_CAR_MAX`。
